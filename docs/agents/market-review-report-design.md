# market-review HTML 리포트 DESIGN RULE

HTML 리포트를 만들 때만 읽는 문서다. 매번 싣지 않으려고 `.claude/agents/market-review.md` 본문에서 뺐다.
리포트는 **메인 대화가** 만든다. market-review 서브에이전트는 메인 대화를 볼 수 없어서, 대화에서 모은 정보를
빠짐없이 넣으라는 아래 규칙을 지킬 수 없다. 서브에이전트에 맡긴 검토 결과는 대화에서 모은 정보의 하나로 넣는다.

HTML 리포트는 **사용자가 "리포트 생성" 을 요청했을 때만** 만든다. 기업마다 궁금한 것이 달라서, 사용자는 대화로
필요한 정보를 다 모은 뒤 마지막에 생성을 요청한다. 그 전에는 조사 결과를 텍스트로 답하고 HTML 을 먼저 만들지
않는다. 생성할 때는 `.claude/agents/market-review.md` 데이터 절의 수집분에 **대화에서 모은 정보를 빠짐없이**
넣는다 — 다 넣은 뒤 대화에 나온 수치·공시·기사를 하나씩 대조해 빠진 것이 없는지 확인하고, 없는 데이터는 "데이터 없음" 으로 남긴다.

목적은 정보를 다 넣으면서도 **넓게 본 뒤 자세히 보는 순서**가 지켜지는 것이다.

## 구조: 큰 그림 → 질문 지도 → 질문별 장

`market-review.md` `## 리포트` 의 텍스트 순서는 HTML 에 쓰지 않는다. 대신 판단 절의 필드(판단·확신도·
`horizon_days`·기준가·진입 구간·목표가·손절가·무효화 조건·`data_as_of`)는 요약의 판단 박스와 Q7 에 빠짐없이 넣는다.

1. **요약 1쪽** — 상단 띠(COMPANY REPORT · 업종 · 작성일 · 가격 기준일) → 종목명 → 의견형 헤드라인 한 줄.
   왼쪽 좁은 열: 판단 박스(녹색 바탕, 판단·horizon·확신도) · 기준가/목표가 괴리/재검토·이탈 가격 · Stock Data
   (시총, 52주, 외국인, PER/PBR, 부채비율) · 월봉 주가 차트 · 1M/3M/6M/12M 수익률. 오른쪽 열: 번호 붙은 핵심
   포인트 3개(굵은 한 줄 + 근거 문단)와 "판단을 바꿀 조건". 하단: Financial Data 표(실적 A, 추정 E 는 색을 달리).
2. **큰 그림 1쪽** — 사업 모델 흐름도(고객 → 회사 → 최종 판매) 아래에 작은 차트 6개(3×2). 연간 매출, 분기
   이익률, 지역(또는 부문) 성장, FCF, 순차입금, 주가처럼 질문 장마다 하나씩 뽑는다. 카드마다 한 줄 결론과
   `자세히 → Qn` 링크.
3. **질문 지도 1쪽** — 질문 카드 그리드. 카드마다 한 줄 답, 신호(좋음·보통·주의·개요 색), 쪽 번호, 장으로 가는 링크.
4. **질문별 장** — 질문 하나에 한 쪽 이상. 순서는 녹색 띠(번호·질문·한 줄 답·신호) → 핵심 수치 3개 → `한눈에`
   (차트 1~3개) → `자세히`(회색 바탕, 표·원문 요약·주석). 같은 주제의 차트와 표는 한 장에 모은다.
5. **부록** — 데이터 출처 표, 참고 기사 링크, 한계, 마지막 줄 "투자 조언이 아닌 의사결정 보조 리포트".

기본 질문은 아래 일곱이다. 대화에서 따로 파고든 주제(예: 설비투자 사용처, 자회사 CB)는 가장 가까운 질문의
`자세히` 에 넣고, 한 장을 채울 만큼 크면 질문을 하나 더 만든다.

| 질문 | 한눈에 | 자세히 |
| --- | --- | --- |
| Q1 무엇을 하는 회사인가? | 제품 구성, 연혁 | 회사 개요(사업 방식·고객·대표 제품·경쟁력), 법인별 제품·단가, 내수·수출, 원재료 |
| Q2 어디서 돈을 버나? | 지역·부문 매출, 법인별 이익 | 법인별 실적 표, 생산능력, 거점·증설 계획 |
| Q3 잘 팔리고 남기나? | 분기 매출, 영업이익 vs 순이익, 연간 추이 | 분기 표(영업외·실효세율 포함), 손익계산서, DART 수익성·성장성 지표 |
| Q4 번 돈이 현금으로 남나? | 영업CF vs CAPEX, 건설중인자산, 투자처 | 설비투자 비율, 현금흐름표, 자산 변동, 파생 지표 |
| Q5 빚은 감당할 만한가? | 순차입금, 앞으로 나갈 돈 | 재무상태표, DART 안정성 지표, 차입 구조, 약정·우발부채, 사채·CB |
| Q6 주가는 싼가? | 밸류에이션, 증권사 의견 | 기술적 지표, 공시·뉴스 일지 |
| Q7 그래서 어떻게 하나? | 판단과 조건, 다음 실적에서 볼 것 | bull/bear, 시나리오 |

## 지면과 차트

- 색은 만원권 팔레트다. 강조색은 녹색 `#1f5c4a` 한 가지(아래 "녹색" 은 모두 이 색). 글자 `#1d2a24`, 보조 글자
  `#5d6b62`, 선 `#cad8cc`, 바탕 `#e2ebe2`, 옅은 칸 `#eef4ee`, 차트의 나머지 막대 `#b5c7ba`, 추정 `#9a6b00`.
  "좋음" 신호는 강조색과 헷갈리지 않게 연두 `#5a9a2e`, "나쁨" 은 빨강 `#c0392b`. 강조색 외의 파랑·녹색은 쓰지 않는다.
- A4 지면 느낌: 연두 바탕 위 흰 `.page`(최대 폭 940px), 상단 녹색 3px 줄.
  인쇄용이라 라이트 고정이고 `@media print` 에서 쪽마다 나눈다.
- 그림·표에 문서 순서대로 `그림 N`·`표 N` 번호를 붙이고, 캡션은 **결론 문장**("분기 매출: 2026Q2 사상 최대")이다.
  캡션 위 녹색 2px 줄, 바로 아래 `자료: 출처, 단위, 기준일` 한 줄.
- 한 차트에 메시지 하나: 말하려는 막대·점만 녹색, 나머지는 회색. 빨강·연두는 적자·기준선 초과 같은 좋음/나쁨에만.
  고점·저점·이벤트·기준선 값은 차트 안에 직접 쓴다.
- 무효화 조건의 가격(이동평균)과 목표가는 주가 차트에 점선으로 그린다.
- 근거 등급을 구분한다: 공시는 녹색, 언론 보도 수치는 회색으로 칠하고 범례에 적는다. 추정(KIS)은 표에서 색을 달리하고
  "컨센서스 아님" 을 쓴다. 계산값에는 `*` 나 "계산값" 표시.
- 한 HTML 파일, 차트는 외부 라이브러리 없이 인라인 SVG. 숫자 열은 `tabular-nums`·우측 정렬.
  760px 이하에서는 1열로 접고 넓은 표는 가로 스크롤.
